# Source Code Directory

This directory contains the Python code for the NIBD Ratio econometric model.

## Structure

The typical structure for model code includes:

```
src/
├── model.py              # Main model implementation
├── data_preprocessing.py # Data loading and preprocessing
├── utils.py              # Utility functions
├── visualization.py      # Plotting and visualization
├── config.py             # Configuration parameters
└── README.md             # This file
```

## Adding Your Code

1. Place your Python code file(s) in this directory
2. If the code was generated by Perplexity AI or other tools, it may need adjustments:
   - Update file paths to point to the `data/` directory
   - Adjust import statements as needed
   - Add error handling and validation
   - Update configuration parameters

## Main Model Script

The main model script should typically:
1. Load data from the `../data/` directory
2. Preprocess and clean the data
3. Train/calibrate the econometric model
4. Generate predictions and evaluate performance
5. Save results and visualizations

## Running the Code

```bash
# From the repository root
python src/model.py

# Or if the code requires command-line arguments
python src/model.py --data data/nibd_calibration_data.csv
```

## Dependencies

Make sure all dependencies are listed in `requirements.txt` at the repository root.
