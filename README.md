# NIBD_Ratio
Econometric Model for Non-interest Bearing Deposit Ratio

## Overview
This repository contains the econometric model and analysis for predicting the Non-Interest Bearing Deposit (NIBD) Ratio. The model uses historical data to calibrate parameters and make predictions.

## Repository Structure
```
NIBD_Ratio/
├── data/               # Directory for CSV data files
│   └── README.md      # Instructions for data files
├── docs/              # Documentation and model development documents
│   └── README.md      # Documentation guidelines
├── src/               # Source code for the model
│   └── README.md      # Code structure and usage
├── requirements.txt   # Python dependencies
└── README.md         # This file
```

## Setup

### Prerequisites
- Python 3.8 or higher
- pip package manager

### Installation
1. Clone this repository:
   ```bash
   git clone https://github.com/chihchen22/NIBD_Ratio.git
   cd NIBD_Ratio
   ```

2. Install required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

**📖 New to this repository? Start with [GETTING_STARTED.md](GETTING_STARTED.md) for step-by-step instructions on adding your files.**

### Adding Data
Place your CSV files containing econometric model data in the `data/` directory. See `data/README.md` for expected data format.

### Running the Model
The main model code is located in the `src/` directory. Refer to `src/README.md` for detailed usage instructions.

### Documentation
Model development documents and related documentation should be placed in the `docs/` directory.
