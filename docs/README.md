# Documentation Directory

This directory contains documentation related to the NIBD Ratio econometric model.

## Contents

Place your model development documents here, including:

- **Model Development Document**: Detailed description of the model methodology, assumptions, and theoretical background
- **Data Dictionary**: Descriptions of variables and features used in the model
- **Calibration Notes**: Documentation of model calibration process and parameters
- **Results and Analysis**: Findings, performance metrics, and interpretations
- **Technical Specifications**: Detailed technical implementation notes

## Supported Formats

You can add documentation in various formats:
- Markdown (`.md`) - Recommended for version control
- PDF (`.pdf`) - For formatted documents
- Word documents (`.docx`) - Will be tracked by git
- Jupyter Notebooks (`.ipynb`) - For interactive documentation with code

## Example Structure

```
docs/
├── model_development.md        # Main model development document
├── data_dictionary.md          # Variable descriptions
├── calibration_notes.md        # Calibration details
├── methodology.pdf             # Detailed methodology (if available)
└── README.md                   # This file
```

## Adding Your Documents

1. Place your model development document(s) in this directory
2. Use descriptive filenames
3. If using Markdown, include a table of contents for longer documents
4. Reference any external resources or papers

## Linking Documents

You can reference documents from the main README or from code comments:
- `See docs/model_development.md for details`
- `Refer to docs/methodology.pdf for theoretical background`
